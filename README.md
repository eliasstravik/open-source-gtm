# Open Source GTM

A community directory of public repos for GTM teams and GTM engineers.

This list covers products, agent skills, libraries, templates, and learning resources for sales, marketing, RevOps, customer success, and growth workflows.

Inclusion bar:

- Every entry has a public repo.
- Software sections require a verified OSI-approved license.
- Mixed-license, fair-code, and source-available tools are separated under `Source-available`.
- Content sections also require a verified license from the repo itself.
- Archived or clearly unmaintained repos are excluded.
